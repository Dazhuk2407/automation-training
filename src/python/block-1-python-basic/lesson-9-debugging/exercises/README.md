# Exercises — Lesson 9: Debugging

У цій папці знаходяться практичні вправи до Lesson 9.

## Файли
- `EXERCISES.md` — опис усіх завдань
- `test_exercises.py` — pytest тести для перевірки виправленого коду

## Як працювати

Для кожної вправи:

1. Прочитайте завдання в `EXERCISES.md`
2. Створіть файл і вставте код як є (з помилками)
3. **Запустіть** — подивіться яка помилка виникає
4. **Дебажте** — використайте print() або breakpoints щоб знайти причину
5. **Виправте** — внесіть мінімальну зміну
6. **Перевірте** — запустіть знову, переконайтесь що працює
7. Запустіть тести:
   ```bash
   pytest test_exercises.py -v
   ```

## Важливо
Не виправляйте код "на око" — сенс вправ у тому, щоб **знайти** помилку через debugging, а не вгадати її.
