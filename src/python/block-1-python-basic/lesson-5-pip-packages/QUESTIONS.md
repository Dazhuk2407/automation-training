# Питання для самоперевірки - Lesson 5: pip

## 🎯 pip Основи

1. **Оновлення pip**
   - Команда для оновлення
   - Чому це важливо?

2. **Встановлення**
   - Команда для встановлення пакету
   - Як встановити конкретну версію?

3. **Перевірка**
   - Команда для списку пакетів
   - Як дізнатися інформацію про пакет?

4. **Видалення**
   - Команда для видалення пакету
   - Як видалити кілька пакетів?

## ✅ Практичні завдання

5. **Оновіть pip:**
   ```bash
   python3 -m pip install --upgrade pip
   ```

6. **Встановіть пакет:**
   ```bash
   pip install requests
   ```

7. **Перевірте встановлення:**
   ```bash
   pip list
   pip show requests
   ```

8. **Видаліть пакет:**
   ```bash
   pip uninstall requests
   ```
