# Вправи — Lesson 24: Failed First

У цій папці знаходяться практичні вправи до Lesson 24.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `exercise_1_ff.py` — вправа 1: реалізувати та перевірити `failed_first`
- `exercise_2_ordering.py` — вправа 2: порядок і крайні випадки перевпорядкування
- `exercise_3_fix_ff.py` — вправа 3: знайти й виправити неправильний очікуваний порядок
- `test_exercises.py` — автоматична перевірка

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. Замініть `pass` на правильний `assert` (функція `failed_first` уже надана у файлі)
3. Запустіть свій файл: `pytest exercise_1_ff.py -v`
4. Коли все зелене — запустіть перевірку: `pytest test_exercises.py -v`
