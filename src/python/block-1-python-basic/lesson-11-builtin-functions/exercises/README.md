# Exercises — Lesson 11: Built-in Functions

У цій папці знаходяться практичні вправи до Lesson 11.

## Файли
- `EXERCISES.md` — опис усіх завдань
- `test_exercises.py` — pytest тести для перевірки

## Як працювати
1. Прочитайте завдання в `EXERCISES.md`
2. Створіть файл та реалізуйте функції
3. Перевірте вручну:
   ```bash
   python exercise_1_info_functions.py
   ```
4. Запустіть тести:
   ```bash
   pytest test_exercises.py -v
   ```
