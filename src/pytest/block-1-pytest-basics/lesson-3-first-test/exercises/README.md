# Вправи — Lesson 3: Перший тест у проєкті

У цій папці знаходяться практичні вправи до Lesson 3.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `test_exercises.py` — автоматична перевірка вашого проєкту

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. Створіть папку `my_project/` з правильною структурою (`src/` + `tests/`)
3. Напишіть код та тести за інструкцією
4. Запустіть свої тести з папки `my_project/`:
   ```bash
   cd my_project
   pytest -v
   ```
5. Коли все зелене — запустіть перевірку з папки `exercises/`:
   ```bash
   pytest test_exercises.py -v
   ```

## Важливо

- Всі вправи використовують структуру `src/` + `tests/`
- Імпортуйте код через `from src.calculator import add`
- Запускайте pytest з кореня `my_project/`
