# Питання для самоперевірки - Lesson 7: Basic Python Syntax

## 🎯 Структура файлу та коментарі

1. **Структура Python файлу**
   - Назвіть основні частини Python-файлу у правильному порядку
   - Для чого потрібен `if __name__ == "__main__"`?

2. **Коментарі vs Docstrings**
   - Різниця між `#` та `"""..."""`?
   - Коли використовувати кожен?
   - Як переглянути docstring функції?

3. **Правильні коментарі**
   - Напишіть коментар, який пояснює функцію, що додає два числа.
   - Напишіть docstring з секціями Args та Returns

## 🔤 Змінні та назвування

4. **Оголошення змінних**
   - Як оголосити int, str, float, bool, None?
   - Чи потрібно вказувати тип при оголошенні?

5. **Правила назвування**
   - Яке ім'я змінної відповідає рекомендаціям PEP 8: myVar, my_var, MyVar, MY_VAR?
   - Чи може змінна починатися з цифри?
   - Які символи дозволені в іменах?

6. **Множинне присвоювання**
   - Як присвоїти три змінні одночасно: `x, y, z = 1, 2, 3`?
   - Як поміняти значення двох змінних?

## ➕ Оператори

7. **Арифметичні оператори**
   - Різниця між `/` та `//`?
   - Що означає `%`?
   - Який результат виразу: `2 + 3 * 4 = ?`

8. **Оператори порівняння**
   - Напишіть код: "перевірити чи x більше 5"
   - Яка різниця між `=` та `==`?

9. **Логічні оператори**
   - Коли вираз з оператором `and` повертає True?
   - Коли вираз з оператором `or` повертає True?
   - Що робить `not`?

## ❌ Типові помилки

10. **Синтаксичні помилки**
    - Виправте: `def func()`
    - Виправте: `if x > 5 print("yes")`
    - Виправте: `text = "Hello' World`

11. **Помилки назвування**
    - Чому `2invalid` неправильна назва?
    - Чому `invalid-name` неправильна?
