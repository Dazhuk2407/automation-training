# Lesson 2: Install and set up an IDE (PyCharm or VS Code)

## Мета уроку

Встановити IDE (PyCharm або VS Code) та підключити Python інтерпретатор до проєкту.
## План

### 2.1 Install and set up IDE
- Встановлення PyCharm або VS Code
- Налаштування Python інтерпретатора
- Підключення до проєкту

## IDE опції

### PyCharm
- Встановіть з [jetbrains.com](https://www.jetbrains.com/pycharm/)
- Community Edition (безплатна) - її повністю достатньо для навчання та розробки
- Professional Edition (платна)

### VS Code
- Встановіть з [code.visualstudio.com](https://code.visualstudio.com/)
- Рекомендується також встановити розширення "Pylance"

## Налаштування інтерпретатора

### PyCharm
1. File → Settings → Project → Python Interpreter
2. Додайте новий інтерпретатор
3. Виберіть Python версію

### VS Code
1. Cmd+Shift+P (macOS) або Ctrl+Shift+P (Windows/Linux)
2. Виберіть Python версію
