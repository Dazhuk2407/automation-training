# Питання для самоперевірки - Lesson 8: PEP 8 and Code Formatting

## 🎯 Теоретичні питання - PEP 8

### 1. Основи PEP 8

**Q1:** Що таке PEP 8?  
**A:** Офіційний посібник зі стилю коду для Python

**Q2:** Скільки пробілів для відступів?  
**A:** 4 пробіли (не Tab!)

**Q3:** Максимальна довжина рядка?  
**A:** 79 символів (код), 72 (коментарі)

### 2. Назвування

**Q4:** Функції та змінні?  
**A:** `snake_case`

**Q5:** Класи?  
**A:** `PascalCase`

**Q6:** Константи?  
**A:** `UPPER_SNAKE_CASE`

### 3. Пробільність

**Q7:** Пробіли навколо операторів?  
**A:** Так: `x = y + 1`

**Q8:** Після коми?  
**A:** Один пробіл: `func(a, b, c)`

### 4. Структура

**Q9:** Порожні рядки між функціями?  
**A:** 2 рядки

**Q10:** Між методами класу?  
**A:** 1 рядок

**Q11:** Порядок імпортів?  
**A:** stdlib → 3rd party → local

## 🛠️ Інструменти

**Q12:** Що робить black?  
**A:** Автоматично форматує код

**Q13:** Команда black?  
**A:** `black myfile.py`

**Q14:** Що робить flake8?  
**A:** Перевіряє PEP 8 (лінтер)

**Q15:** Різниця flake8 vs pylint?  
**A:** flake8=стиль, pylint=якість+рейтинг

## 🐛 Помилки

**Q16:** Помилка в `x=1+2`?  
**A:** Без пробілів. Правильно: `x = 1 + 2`

**Q17:** Помилка в `def MyFunction():`?  
**A:** PascalCase. Правильно: `def my_function():`

**Q18:** Помилка в `class user_profile:`?  
**A:** snake_case. Правильно: `class UserProfile:`
