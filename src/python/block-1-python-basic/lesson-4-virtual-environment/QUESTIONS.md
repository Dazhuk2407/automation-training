# Питання для самоперевірки - Lesson 4: venv

## 🎯 Віртуальне середовище

1. **Навіщо потрібен venv?**
   - Які проблеми він вирішує?
   - Як це допомагає при розробці?

2. **Створення**
   - Команда для створення venv
   - Де він створюється?

3. **Активація**
   - Команда для активації на Linux/macOS
   - Команда для активації на Windows
   - Як дізнатися що venv активний?

4. **Деактивація**
   - Команда для деактивації
   - Що буває після деактивації?

## ✅ Практичні завдання

5. **Створіть venv:**
   ```bash
   python3 -m venv venv
   ```

6. **Активуйте:**
   ```bash
   source venv/bin/activate  # macOS/Linux
   ```

7. **Перевірте що активовано:**
   - У терміналі має бути `(venv)` префікс
   - `which python3` має показати шлях в venv

8. **Деактивуйте:**
   ```bash
   deactivate
   ```
