# Приклади — Lesson 23: Last Failed

> ⚠️ Реальний `pytest --lf` показано лише як `bash`-команди у `README.md` уроку.
> Тут — **чисті функції-симуляції** логіки `--lf` на звичайних даних (списки та dict),
> щоб її можна було протестувати без запуску pytest усередині pytest.

## Файли

- `example_1_lf_concept.py` — базова ідея `--lf`: із результатів прогону вибрати впалі (4 тести)
- `example_2_lf_logic.py` — повна логіка `last_failed`, зокрема поведінка `--lfnf` (5 тестів)
- `example_3_cache_state.py` — симуляція запису/читання «кешу» між прогонами, без файлів (5 тестів)

## Як працювати

1. Запустіть кожен приклад:
   ```bash
   pytest example_1_lf_concept.py -v
   pytest example_2_lf_logic.py -v
   pytest example_3_cache_state.py -v
   ```
2. Прочитайте функції-симуляції — саме так `--lf` міркує «під капотом»:
   бере минулі результати з кешу і залишає тільки впалі.
