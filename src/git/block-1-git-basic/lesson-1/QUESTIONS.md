# Питання для самоперевірки - Lesson 1: Основи Git

Після вивчення цього уроку ви повинні мати змогу відповісти на наступні питання:

## 🎯 Базові Концепції

1. **Що таке Git?**
   - Для чого він потрібен?
   - Чи Git та GitHub це те саме?
   - Яка різниця між Git та GitHub?

2. **Встановлення Git**
   - Як встановити Git на вашу систему?
   - Як перевірити що Git встановлено?
   - Команда для перевірки версії

3. **Початкові налаштування**
   - Які налаштування потрібно зробити перед першим використанням?
   - Команди для встановлення user.name та user.email

## 📁 Репозиторій та Комміти

4. **Що таке репозиторій?**
   - Як ініціалізувати новий репозиторій?
   - Що буває в папці `.git`?

5. **Перший коміт**
   - Три кроки для створення першого комітуючи
   - `git add`, `git commit` що вони роблять?

6. **Git Status та Git Log**
   - Команда для перевірки стану репозиторію
   - Коли файл "untracked"?
   - Коли файл "staged"?
