# Вправи — Lesson 19: Filter by Name

У цій папці знаходяться практичні вправи до Lesson 19.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `exercise_1_filter.py` — вправа 1: відбір за підрядком імені
- `exercise_2_expressions.py` — вправа 2: вирази `and` / `or` / `not`
- `exercise_3_fix_filter.py` — вправа 3: знайти і виправити неправильний відбір
- `test_exercises.py` — автоматична перевірка

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. У вправах 1–2 замініть `pass` на правильний `assert` (функція `select_by_name` вже готова)
3. Запустіть свій файл: `pytest exercise_1_filter.py -v`
4. У вправі 3 знайдіть падаючий тест і виправте очікуваний результат
5. Коли все зелене — запустіть перевірку: `pytest test_exercises.py -v`
