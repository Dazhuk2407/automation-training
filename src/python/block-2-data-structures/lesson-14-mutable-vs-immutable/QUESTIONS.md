## 📋 Основи

1. **Які типи Python — mutable, а які — immutable?**
   - До якої категорії належать list, tuple, dict, str, int, set?

2. **Що означає "змінити об'єкт на місці"?**
   - Чим `items.append(4)` відрізняється від `name.upper()`?
   - Що повертає кожен з цих методів?

3. **Що станеться з `other` після `items.append(4)`?**
   ```python
   items = [1, 2, 3]
   other = items
   items.append(4)
   ```
   - Чому `other` теж змінився?

## 🔧 Side effects

4. **Що таке побічний ефект (side effect)?**

5. **Як уникнути side effects при передачі dict у функцію?**
   - Два способи: `{**original}` та `.copy()`

6. **Чому `def func(items=[])` — це баг?**

   - Як виправити?
