# Exercises — Lesson 10: Data Types

У цій папці знаходяться практичні вправи до Lesson 10.

## Файли
- `EXERCISES.md` — опис усіх завдань
- `test_exercises.py` — pytest тести для перевірки частини вправ

## Як працювати
1. Відкрийте `EXERCISES.md`
2. Створіть потрібні `.py` файли
3. Реалізуйте рішення
4. Перевірте вручну:
   ```bash
   python exercise_1_all_types.py
   ```
5. Запустіть тести:
   ```bash
   pytest test_exercises.py -v
   ```
