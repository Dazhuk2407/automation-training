# Lesson 1: Install Python and prepare your working environment

## Мета уроку

Встановити Python та підготувати робоче середовище для розробки.

## План

### 1.1 Install Python
- Встановлення Python 3.9+
- Перевірка версії через термінал
- macOS: Homebrew, Windows: python.org

### Встановлення Python

Перевірте чи встановлено Python:

```bash
python3 --version
```

Якщо потрібно встановити:
- **macOS (Homebrew):**
  ```bash
  brew install python
  ```

- **Windows:** Завантажте з [python.org](https://www.python.org/downloads/)

- **Linux (Ubuntu/Debian):**
  ```bash
  sudo apt-get install python3
  ```

### Перевірка встановлення

```bash
python3 --version
pip3 --version
```
