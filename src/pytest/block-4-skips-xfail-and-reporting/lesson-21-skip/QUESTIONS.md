# Питання для самоперевірки — Lesson 21: Skip Tests

## 🧠 Навіщо і коли

1. **Навіщо пропускати тест замість того щоб його видалити?**
   - Що дає видимість пропуску у звіті?
   - Наведіть 2-3 ситуації коли skip доречний

2. **Чому пропущений тест — це НЕ падіння?**
   - Як skip впливає на exit code (`0` чи ні)?
   - Як skip рахується у підсумку pytest?

## ⚙️ Три способи пропуску

3. **Коли використовувати `@pytest.mark.skip`, а коли `@pytest.mark.skipif`?**
   - Чим вони відрізняються?
   - Наведіть приклад для кожного

4. **Коли потрібен імперативний `pytest.skip()` замість декоратора?**
   - Чому «динамічна умова» вимагає саме імперативного пропуску?
   - Що станеться з рештою тесту після виклику `pytest.skip()`?

5. **Що приймає `@pytest.mark.skipif` як перший аргумент?**
   - Вираз-умову чи готовий результат?
   - Коли обчислюється ця умова?

## 📝 Reason

6. **Чому `reason` обовʼязковий?**
   - Що ви втрачаєте якщо пропустити його?
   - Яким прапорцем показати причини пропусків у звіті?

7. **Що покаже pytest у звіті для `@pytest.mark.skip(reason="...")`?**
   - Як виглядає рядок для пропущеного тесту?

## 🔍 Skip vs xfail

8. **Яка різниця між `skip` та `xfail`?**
   - Чи виконується тіло тесту у кожному випадку?
   - Коли доречніший `xfail`?

## 💡 Практика

9. **Чому закоментувати тест — гірше за `@pytest.mark.skip`?**
   - Що станеться з видимістю тесту?
   - Хто дізнається про причину через півроку?

10. **Дано платформо-залежний тест, що працює лише на Windows. Як його правильно оформити?**
    - Який маркер використати?
    - Яку умову передати?
