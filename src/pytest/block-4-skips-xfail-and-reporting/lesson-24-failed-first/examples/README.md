# Приклади — Lesson 24: Failed First

Реальний `pytest --ff` міняє порядок запуску тестів. Щоб це можна було
**протестувати без запуску pytest всередині pytest**, приклади моделюють
логіку `--ff` звичайними функціями-симуляціями. Функція `failed_first`
приймає список тестів і словник результатів минулого прогону та повертає
**новий порядок** — впалі спочатку, решта потім.

## Файли

- `example_1_ff_concept.py` — концепція `failed_first`: впалі першими, решта потім (5 тестів)
- `example_2_ff_logic.py` — деталі логіки: збереження відносного порядку, крайні випадки (5 тестів)
- `example_3_lf_vs_ff.py` — `last_failed` (`--lf`) vs `failed_first` (`--ff`) на одних даних (5 тестів)

## Як працювати

1. Запустіть кожен приклад:
   ```bash
   pytest example_1_ff_concept.py -v
   pytest example_2_ff_logic.py -v
   pytest example_3_lf_vs_ff.py -v
   ```
2. Зверніть увагу: у `example_3_lf_vs_ff.py` обидві функції працюють на
   **одних і тих самих даних** — так видно різницю між `--lf` (лише впалі)
   і `--ff` (впалі першими + усі решта).
