# Приклади — Lesson 2: Структура pytest проєкту

## Файли

- `example_1_project_structure.txt` — дерево стандартного pytest проєкту
- `example_2_pytest_ini.ini` — приклад конфігурації pytest
- `example_3_conftest.py` — заглушка conftest.py (без фікстур)

## Як працювати

1. Перегляньте `example_1_project_structure.txt` — це шаблон для ваших проєктів
2. Скопіюйте `example_2_pytest_ini.ini` → `pytest.ini` у свій проєкт
3. Скопіюйте `example_3_conftest.py` → `tests/conftest.py` у свій проєкт
