# Вправи — Lesson 20: Test Suites

У цій папці знаходяться практичні вправи до Lesson 20.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `exercise_1_suite.py` — вправа 1: класифікація тестів у набори (`suite_of`)
- `exercise_2_organize.py` — вправа 2: підрахунок тестів у наборах (`count_suites`)
- `exercise_3_fix_suite.py` — вправа 3: знайти і виправити помилку в класифікації
- `test_exercises.py` — автоматична перевірка

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. У вправах 1-2 замініть `pass` на правильний `assert`
3. У вправі 3 знайдіть падаючий тест і виправте очікуване значення
4. Запустіть свій файл: `pytest exercise_1_suite.py -v`
5. Коли все зелене — запустіть перевірку: `pytest test_exercises.py -v`
