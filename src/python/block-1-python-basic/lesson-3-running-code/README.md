# Lesson 3: Running Python code from terminal and IDE

## Мета уроку

Навчитися запускати Python код з терміналу та IDE.

## План

### 1.3 Running Python code from terminal and IDE
- Запуск скриптів з терміналу
- Запуск скриптів з IDE
- Різниця в способах запуску
- Передача аргументів

## Запуск з терміналу

```bash
# Простий запуск
python3 script.py

# З аргументами
python3 script.py arg1 arg2

# Вивід в файл
python3 script.py > output.txt

# Інтерактивний режим
python3
>>> print("Hello")
>>> exit()
```

## Запуск з IDE

### PyCharm
- Right-click на файл → Run
- Ctrl+Shift+F10 (виконати файл)
- Ctrl+Alt+F10 (модуль)

### VS Code
- Run Code розширення
- F5 для Debug
- Ctrl+F5 для Run
