## 🎯 Функції

1. **print()**
   - Як вивести текст?
   - Як вивести кілька значень?
   - Параметри sep та end?

2. **input()**
   - Як читати від користувача?
   - Який тип повертає input()?
   - Як конвертувати вхід?

3. **dir()**
   - Для чого потрібен?
   - Як дізнатися методи об'єкта?

4. **id()**
   - Що повертає id()?
   - Коли це використовується?
   - Різниця між `==` та `is`?

## ✅ Практичні завдання

5. **print() варіанти:**
   ```python
   print("Hello", "World", sep=" - ")
   print("No newline", end="")
   ```

6. **input() та конвертація:**
   ```python
   name = input("Name: ")
   age = int(input("Age: "))
   ```

7. **dir() на різних об'єктах:**
   ```python
   print(dir([]))    # Методи списку
   print(dir(""))    # Методи рядка
   ```

8. **id() для порівняння:**
   ```python
   a = [1, 2]
   b = a
   c = [1, 2]
   print(id(a) == id(b))  # True
   print(id(a) == id(c))  # False
   ```
