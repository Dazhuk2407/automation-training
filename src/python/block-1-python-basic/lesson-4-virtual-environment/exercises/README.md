# Вправи - Lesson 4: venv

## Завдання 1: Створіть venv

```bash
# Перейдіть в папку уроку
cd lesson-4

# Створіть venv
python3 -m venv venv

# Перевірте що папка створена
ls -la venv/
```

## Завдання 2: Активуйте venv

```bash
# На macOS/Linux
source venv/bin/activate

# Ви маєте побачити (venv) префікс в терміналі
```

## Завдання 3: Перевірте інтерпретатор

```bash
# Перевірте який Python використовується
which python3

# Має показати шлях в папку venv
```

## Завдання 4: Деактивуйте venv

```bash
deactivate

# (venv) префікс має зникнути
```
