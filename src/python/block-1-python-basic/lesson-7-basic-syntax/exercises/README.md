# Вправи - Lesson 7: Basic Python syntax

## Завдання 1: Структурований скрипт

Створіть файл `example.py` з цією структурою:

```python
"""
Опис модуля - що робить цей скрипт?
"""

# Константи
AUTHOR = "Your Name"

# Функція
def calculate_sum(a, b):
    """Додати два числа."""
    return a + b

# Головний код
if __name__ == "__main__":
    result = calculate_sum(5, 3)
    print(f"Result: {result}")
```

Запустіть:
```bash
python3 example.py
```

