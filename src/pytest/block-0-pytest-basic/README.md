# Block 1: Pytest Basics

Фреймворк для тестування та автоматизації тестів на Python.

## 📚 Уроки (8 занять)

### Lesson 1: Основи Pytest
- Встановлення та налаштування
- Написання простих тестів
- Запуск тестів
- Асерти

### Lesson 2: Фікстури
- Setup/teardown
- Параметризовані фікстури
- Область дії фікстур (scope)

### Lesson 3: Параметризація тестів
- @pytest.mark.parametrize
- Множественні параметри
- Динамічна параметризація

### Lesson 4: Маркери та фільтрація
- Створення власних маркерів
- Фільтрація тестів
- Умовне пропускання тестів

### Lesson 5: Плагіни Pytest
- pytest-html (звіти)
- pytest-xdist (паралельне виконання)
- pytest-timeout (таймаути)

### Lesson 6: Моки та патчінг
- unittest.mock
- Мокування функцій
- Перевірка викликів

### Lesson 7: Структурування тестів
- Page Object Model
- Best practices
- Організація проєкту

### Lesson 8: Інтеграційне тестування
- Тестування API
- Робота з базами даних
- End-to-end тести

## 🚀 Як почати

1. Почніть з `lesson-1`
2. Прочитайте README в папці уроку
3. Вивчіть файли в `examples/`
4. Виконайте вправи в `exercises/`
5. Відповідайте на питання в `QUESTIONS.md`

- На урок: 2.5 години в середньому
- Рекомендовано: Тижні 3-4
