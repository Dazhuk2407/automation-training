# Exercises — Lesson 12: Python Typing

У цій папці знаходяться практичні вправи до Lesson 12.

## Файли
- `EXERCISES.md` — опис усіх завдань
- `test_exercises.py` — pytest тести для перевірки

## Як працювати
1. Прочитайте завдання в `EXERCISES.md`
2. Створіть файл та реалізуйте функції з type hints
3. Перевірте вручну:
   ```bash
   python exercise_1_basic_type_hints.py
   ```
4. Запустіть тести:
   ```bash
   pytest test_exercises.py -v
   ```
5. Для exercise 6 — додатково запустіть mypy:
   ```bash
   mypy exercise_6_mypy_validation.py
   ```
