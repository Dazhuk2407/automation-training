# Block 1: Python Basics

Основи мови Python для розуміння фундаментальних концепцій, необхідних для тестування.

## 📚 Уроки (8 занять)

### Lesson 1: Змінні та типи даних
- Базові типи даних (int, str, float, bool)
- Змінні та присвоювання значень
- Методи та властивості типів

### Lesson 2: Оператори та умовні конструкції
- Арифметичні оператори
- Логічні оператори
- if, elif, else конструкції

### Lesson 3: Цикли
- for цикли
- while цикли
- break та continue

### Lesson 4: Функції
- Визначення функцій
- Аргументи та параметри
- Return значення

### Lesson 5: Об'єктно-орієнтоване програмування
- Класи та об'єкти
- Методи та атрибути
- Наслідування

### Lesson 6: Вбудовані структури даних
- Списки (List)
- Словники (Dict)
- Набори (Set)
- Кортежі (Tuple)

### Lesson 7: Обробка винятків
- try, except, finally
- Власні винятки
- Логування помилок

### Lesson 8: Модулі та пакети
- Імпорт модулів
- Створення власних модулів
- pip та встановлення пакетів

## 🚀 Як почати

1. Почніть з `lesson-1`
2. Прочитайте README в папці уроку
3. Вивчіть файли в `examples/`
4. Виконайте вправи в `exercises/`
5. Відповідайте на питання в `QUESTIONS.md`
6. Запустіть тести: `pytest exercises/`

## ⏰ Рекомендований час

- Всього: ~20 годин
- На урок: 2.5 години в середньому
- Рекомендовано: Тижні 1-2
