# Block 1: Linux Basics

Вивчення основ Linux для розуміння операційної системи та командного рядка.

## 📚 Уроки (8 занять)

### Lesson 1: Основи Linux та Командний Рядок
- Що таке Linux
- Файлова система Linux
- Основні команди (ls, cd, pwd, mkdir, rm)
- Навігація по системі

### Lesson 2: Робота з Файлами та Папками
- Створення, копіювання, переміщення файлів
- Видалення файлів
- Перегляд вмісту файлів (cat, less, head, tail)
- Пошук файлів (find, locate)

### Lesson 3: Дозволи та Власники (Permissions)
- Розуміння дозволів (rwx)
- Команда chmod (змінення дозволів)
- Команда chown (змінення власника)
- Користувачі та групи

### Lesson 4: Користувачі та Групи
- Додавання та видалення користувачів
- Керування групами
- sudo та권限
- Переключення користувачів (su, sudo)

### Lesson 5: Текстові Редактори (vim, nano)
- Nano редактор - основи
- Vim редактор - основи
- Редагування конфігураційних файлів
- Best practices

### Lesson 6: Процеси та Керування Системою
- Перегляд процесів (ps, top, htop)
- Зупинення та перезавантаження процесів
- Керування сервісами (systemctl)
- Моніторинг системи

### Lesson 7: Мережа та SSH
- Основи мережевих команд (ping, ifconfig, netstat)
- SSH - безпечне підключення
- Трансфер файлів (scp, sftp)
- Туннелювання

### Lesson 8: Скрипти та Автоматизація
- Bash скрипти - основи
- Змінні та умовні оператори
- Цикли та функції
- Автоматизація завдань (cron)
