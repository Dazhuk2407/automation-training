# Вправи - Lesson 2: IDE Setup

## Завдання 1: Встановіть IDE

Виберіть один з варіантів:
- [ ] PyCharm Community Edition
- [ ] VS Code

## Завдання 2: Налаштуйте інтерпретатор

- [ ] Відкрийте IDE
- [ ] Налаштуйте Python інтерпретатор (версія 3.9+)
- [ ] Переконайтеся що інтерпретатор вибраний

## Завдання 3: Запустіть файл

- [ ] Створіть новий файл `hello.py`
- [ ] Напишіть код:
  ```python
  print("Hello from IDE!")
  ```
- [ ] Запустіть файл з IDE (кнопка Run)

## Завдання 4: Перевірте налаштування

Створіть файл `check_env.py`:

```python
import sys
import os

print(f"Python: {sys.version}")
print(f"Interpreter: {sys.executable}")
print(f"Path: {os.getcwd()}")
```

Запустіть його в IDE.

---

**✅ Коли файл запускається з IDE - переходьте до Lesson 3**
