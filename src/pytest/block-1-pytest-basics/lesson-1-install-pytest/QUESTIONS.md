# Питання - Lesson 1: Install Pytest

## 🎯 Installation Questions

1. **Що таке pytest?**
   - A: Фреймворк для тестування Python

2. **Як встановити pytest?**
   - A: `pip install pytest`

3. **Як перевірити версію pytest?**
   - A: `pytest --version`

4. **Яка мінімальна версія Python для pytest?**
   - A: Python 3.8+

5. **Навіщо використовувати віртуальне середовище?**
   - A: Ізоляція залежностей проєкту

6. **Як активувати venv на macOS?**
   - A: `source venv/bin/activate`

7. **Що зберігається в requirements.txt?**
   - A: Список залежностей проєкту

8. **Як встановити залежності з requirements.txt?**
   - A: `pip install -r requirements.txt`
