# Вправи — Lesson 10: Tuples

## Файли

- `EXERCISES.md` — опис завдань
- `exercise_1_basics.py` — створення, доступ, immutability
- `exercise_2_unpacking.py` — розпакування tuples
- `exercise_3_functions.py` — повернення tuples з функцій
- `exercise_4_test_data.py` — tuples як тестові дані
- `test_exercises.py` — автоматична перевірка

## Як працювати

1. Прочитайте `EXERCISES.md`
2. Замініть `pass` на правильний код
3. Запустіть: `pytest exercise_1_basics.py -v`
4. Перевірка: `pytest test_exercises.py -v`
