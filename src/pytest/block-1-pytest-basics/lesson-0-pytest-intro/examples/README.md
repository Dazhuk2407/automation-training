# Приклади — Lesson 0: Знайомство з Pytest

У цій папці знаходяться приклади до Lesson 0.

## Файли

- `example_1_simple_test.py` — найпростіший тест: функція + assert
- `example_2_asserts.py` — різні види перевірок (assert)
- `example_3_exceptions.py` — тестування винятків через `pytest.raises`

## Як працювати

1. Запустіть приклад:
   ```bash
   pytest example_1_simple_test.py -v
   ```
2. Прочитайте код та коментарі
3. Спробуйте змінити значення в `assert` щоб побачити як тест падає
4. Переходьте до наступного прикладу
