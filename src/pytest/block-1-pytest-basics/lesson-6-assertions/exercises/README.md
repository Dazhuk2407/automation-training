# Вправи — Lesson 6: Assertions

У цій папці знаходяться практичні вправи до Lesson 6.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `exercise_1_comparison.py` — вправа 1: порівняння та boolean
- `exercise_2_types_and_membership.py` — вправа 2: типи та належність
- `exercise_3_exceptions.py` — вправа 3: pytest.raises
- `exercise_4_messages.py` — вправа 4: assert з повідомленнями
- `exercise_5_introspection.py` — вправа 5: розуміння pytest diff
- `test_exercises.py` — автоматична перевірка

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. Замініть `pass` на правильний `assert`
3. Запустіть свій файл: `pytest exercise_1_comparison.py -v`
4. Коли все зелене — запустіть перевірку: `pytest test_exercises.py -v`
