# Lesson 1: Основи Linux та Командний Рядок

## Що таке Linux?

Linux - це вільна операційна система з відкритим кодом. Вона використовується на серверах, комп'ютерах, смартфонах та інших пристроях.

## Файлова Система Linux

Linux має ієрархічну файлову систему з корінню на `/`:

```
/
├── bin/              # Виконувані програми
├── etc/              # Файли конфігурації
├── home/             # Домашні папки користувачів
├── tmp/              # Тимчасові файли
├── usr/              # Користувальницькі програми
├── var/              # Змінні дані
└── root/             # Домашня папка root
```

## Основні Команди

### Навігація

```bash
# Показати поточну папку
pwd

# Перелістити вміст папки
ls
ls -l        # Детальний список
ls -la       # Включить приховані файли

# Змінити поточну папку
cd /path/to/folder
cd ~         # Домашня папка
cd ..        # На рівень вище
cd -         # Попередня папка
```

### Робота з Папками

```bash
# Створити папку
mkdir folder_name

# Створити вкладені папки
mkdir -p path/to/folder

# Видалити порожню папку
rmdir folder_name

# Видалити папку з вмістом
rm -r folder_name
```

### Робота з Файлами

```bash
# Створити порожній файл
touch file.txt

# Копіювати файл
cp file.txt copy.txt

# Переміщувати файл
mv file.txt new_location/

# Видалити файл
rm file.txt

# Переглянути вміст
cat file.txt
```

### Пошук

```bash
# Пошук файлів за назвою
find / -name "filename"

# Пошук за типом
find . -type f -name "*.txt"
```

## Структура Командного Рядка

```
command [options] [arguments]

Приклад:
ls -l /home
│   │  │
│   │  └─ Аргумент (на яку папку дивитися)
│   └─ Опція (детальний список)
└─ Команда (список вмісту)
```

## Важливі Концепції

### Абсолютний та Відносний Шляхи

```bash
# Абсолютний шлях (від кореня)
/home/user/documents/file.txt

# Відносний шлях (від поточної папки)
documents/file.txt
../file.txt
./file.txt
```

### Спеціальні Символи

```bash
~       # Домашня папка (/home/username)
.       # Поточна папка
..      # Папка на рівень вище
*       # Wildcard - будь-які символи
?       # Один символ
```
