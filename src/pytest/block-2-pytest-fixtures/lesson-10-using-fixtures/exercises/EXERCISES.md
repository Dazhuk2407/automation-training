# Вправи — Lesson 10: Using Fixtures

---

## 🏋️ Вправа 1: Передати фікстуру як параметр (EASY)

**Файл:** `exercise_1_pass_fixture.py`

У файлі вже оголошені фікстури. Ваше завдання — прийняти їх як параметр і написати `assert`.

| Тест | Що перевірити |
|------|--------------|
| `test_username` | фікстура `username` дорівнює "alice" |
| `test_username_type` | `username` — це `str` |
| `test_number` | фікстура `number` дорівнює 42 |
| `test_number_positive` | `number` більше за 0 |
| `test_items_length` | фікстура `items` містить 3 елементи |

---

## 🏋️ Вправа 2: Кілька фікстур в одному тесті (MEDIUM)

**Файл:** `exercise_2_multiple.py`

Тести приймають **дві** фікстури. Прийміть обидві як параметри і напишіть `assert`.

| Тест | Фікстури | Що перевірити |
|------|----------|--------------|
| `test_user_role` | `user` | роль користувача — "admin" |
| `test_config_timeout` | `config` | `timeout` дорівнює 30 |
| `test_user_and_config` | `user`, `config` | ім'я "alice" та `retries` == 3 |
| `test_url_is_https` | `base_url` | URL починається з "https://" |
| `test_all_three` | `user`, `config`, `base_url` | всі три значення разом |

## 🏋️ Вправа 3: Виправити падаючий тест (MEDIUM)

**Файл:** `exercise_3_fix_usage.py`

Один тест навмисно падає: він очікує **не те** значення з фікстури.

**Завдання:**
1. Запустіть файл — один тест падає
2. Прочитайте вивід pytest: яке значення повертає фікстура насправді?
3. Виправте `assert` так, щоб тест проходив
4. Заповніть блок `# ВІДПОВІДЬ:`

---

## ✅ Перевірка

```bash
pytest test_exercises.py -v
```

### Критерії:

- [ ] Всі тести проходять
- [ ] Фікстури передані як параметри (не викликані напряму `fixture()`)
- [ ] Імена параметрів точно збігаються з іменами фікстур
- [ ] У вправі 3 виправлено падаючий тест і заповнено блок `# ВІДПОВІДЬ:`
