# Block 6: OOP (Object-Oriented Programming)

Об'єктно-орієнтоване програмування — спосіб організувати код навколо об'єктів, що поєднують дані та поведінку. Для QA це основа Page Object Model, API-клієнтів і фікстур. Цей блок веде від першого класу до magic methods.

## 📚 Уроки (Week 5–6)

### Lesson 42: Classes and Objects
📁 Папка: `lesson-42-classes-and-objects`
- Клас vs об'єкт (екземпляр)
- Атрибути та методи, `self`

### Lesson 43: Constructor (__init__)
📁 Папка: `lesson-43-constructor-init`
- Ініціалізація об'єкта
- Параметри та атрибути екземпляра

### Lesson 44: Instance and Class Methods
📁 Папка: `lesson-44-instance-and-class-methods`
- Методи екземпляра (`self`)
- Методи класу (`@classmethod`, `cls`)

### Lesson 45: Static Methods
📁 Папка: `lesson-45-static-methods`
- `@staticmethod`
- Коли статичний метод, а коли класу

### Lesson 46: Inheritance Basics
📁 Папка: `lesson-46-inheritance`
- Наслідування, `super()`
- Перевизначення методів

### Lesson 47: Python OOP Concepts
📁 Папка: `lesson-47-oop-concepts`
- Інкапсуляція, поліморфізм, абстракція
- Приватні атрибути (`_`, `__`)

### Lesson 48: Overview of Magic Methods
📁 Папка: `lesson-48-magic-methods`
- `__str__`, `__repr__`, `__eq__`, `__len__`
- Dunder-методи у тестах
