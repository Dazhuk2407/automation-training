# Вправи — Lesson 0: Знайомство з Pytest

У цій папці знаходяться практичні вправи до Lesson 0.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `exercise_1_even_odd.py` — вправа 1: тестування парних/непарних чисел
- `exercise_2_string_utils.py` — вправа 2: тестування роботи з рядками
- `exercise_3_calculator.py` — вправа 3: тестування калькулятора з винятками
- `test_exercises.py` — автоматична перевірка ваших рішень

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. Відкрийте файл вправи (наприклад `exercise_1_even_odd.py`)
3. Допишіть тести замість `pass` (кожен TODO пояснює що потрібно)
4. Запустіть свій файл:
   ```bash
   pytest exercise_1_even_odd.py -v
   ```
5. Коли все зелене — запустіть перевірку:
   ```bash
   pytest test_exercises.py -v
   ```

## Важливо

- Кожна вправа має готові функції — ви пишете лише **тести**
- Не змінюйте функції, тільки дописуйте тести
- Всі тести мають використовувати `assert`
