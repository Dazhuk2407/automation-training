## 📖 Теорія

### 1. Базовий f-string

f-string (formatted string literal) — це рядок з літерою `f` перед лапками. У фігурних дужках `{}` можна вставляти змінні:

```python
name = "Alice"
greeting = f"Hello {name}"   # "Hello Alice"
```

До появи f-strings (Python 3.6) використовували `.format()` або `%`:

```python
name = "Alice"

# Старий спосіб — %
"Hello %s" % name

# Старий спосіб — .format()
"Hello {}".format(name)

# ✅ Сучасний спосіб — f-string
f"Hello {name}"
```

Чому f-strings краще:
- **Читабельніше** — змінна стоїть прямо там, де вона з'являється у рядку
- **Коротше** — не треба окремо перелічувати аргументи в кінці
- **Швидше** — f-strings обробляються ефективніше за `.format()`

---

### 2. Вирази всередині f-string

У дужки можна класти не лише змінні, а й будь-який вираз:

```python
f"{2 + 2}"              # "4"
f"{10 * 3}"             # "30"

user = {"name": "Bob"}
f"{user['name']}"       # "Bob"

name = "alice"
f"{name.upper()}"       # "ALICE"
f"{len(name)}"          # "5"
```

Python обчислює вираз, а потім підставляє результат у рядок.

---

### 3. Форматування чисел

Специфікатор пишеться після двокрапки: `{значення:специфікатор}`.

```python
price = 19.5
f"{price:.2f}"          # "19.50"  — 2 знаки після коми

n = 1234567
f"{n:,}"                # "1,234,567"  — роздільник тисяч

f"{7:03d}"              # "007"  — доповнити нулями до 3 цифр
```

- `.2f` — фіксована точка, 2 знаки після коми
- `,` — розділяє тисячі комами
- `03d` — ціле число, ширина 3, доповнене нулями зліва

---

### 4. Відсотки

Специфікатор `%` множить число на 100 і додає знак відсотка:

```python
ratio = 0.8
f"{ratio:.1%}"          # "80.0%"

f"{0.1234:.1%}"         # "12.3%"
f"{1:.0%}"              # "100%"
```

Зручно для звітів про покриття тестами чи pass rate.

---

### 5. Вирівнювання і ширина

Для таблиць і звітів текст вирівнюють у колонках заданої ширини:

```python
f"{'Alice':<10}"        # "Alice     "  — ліворуч
f"{'Alice':>10}"        # "     Alice"  — праворуч
f"{'Alice':^10}"        # "  Alice   "  — по центру
```

- `<` — вирівняти ліворуч
- `>` — вирівняти праворуч
- `^` — вирівняти по центру

Число після символу — ширина поля.

---

### 6. `=` для дебагу

Знак `=` всередині дужок виводить і назву змінної, і її значення:

```python
x = 5
f"{x=}"                 # "x=5"

status = "PASSED"
f"{status=}"            # "status=PASSED"
```

Дуже зручно під час діагностики тестів замість `print("x =", x)`.

---

### 7. Багаторядкові f-strings і QA-звіти

Специфікатори можна комбінувати для формування рядків звіту:

```python
def format_result(passed, total):
    ratio = passed / total
    return f"PASSED: {passed}/{total} ({ratio:.1%})"

format_result(8, 10)    # "PASSED: 8/10 (80.0%)"
```

Багаторядковий звіт з потрійними лапками:

```python
name = "login_test"
duration = 1.234
report = f"""Test: {name}
Duration: {duration:.2f}s
Status: PASSED"""
```

## ⚠️ Типові помилки

### Лапки того ж типу всередині f-string

```python
user = {"name": "Bob"}

# ❌ SyntaxError — подвійні лапки всередині подвійних
# f"{user["name"]}"

# ✅ Використати інший тип лапок
f"{user['name']}"
```

### Забути літеру f

```python
name = "Alice"

# ❌ Виведе буквально "Hello {name}"
"Hello {name}"

# ✅ f перед лапками
f"Hello {name}"
```

### Складна логіка всередині f-string

```python
# ❌ Важко читати
f"{'PASS' if passed == total else 'FAIL: ' + str(total - passed)}"

# ✅ Винести у змінну
status = "PASS" if passed == total else f"FAIL: {total - passed}"
f"{status}"
```
