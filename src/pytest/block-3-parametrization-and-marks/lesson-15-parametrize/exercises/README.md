# Вправи — Lesson 15: Parametrize

У цій папці знаходяться практичні вправи до Lesson 15.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `exercise_1_parametrize.py` — вправа 1: базовий parametrize (замініть `pass` на `assert`)
- `exercise_2_cases.py` — вправа 2: допишіть набори даних (звичайні, межові, негативні)
- `exercise_3_fix_params.py` — вправа 3: виправте неправильний набір даних
- `test_exercises.py` — автоматична перевірка

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. Для вправи 1 — замініть `pass` на правильний `assert`
3. Для вправи 2 — допишіть кортежі даних у списки `parametrize`
4. Для вправи 3 — знайдіть і виправте неправильний кортеж
5. Запустіть свій файл: `pytest exercise_1_parametrize.py -v`
6. Коли все зелене — запустіть перевірку: `pytest test_exercises.py -v`
