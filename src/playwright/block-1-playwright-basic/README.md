# Block 1: Playwright Basics

Бібліотека для автоматизації взаємодії з веб-браузерами.

## 📚 Уроки (8 занять)

### Lesson 1: Основи Playwright
- Встановлення та налаштування
- Запуск браузера
- Навігація по сторінках
- Селектори та пошук елементів

### Lesson 2: Селектори та пошук елементів
- CSS селектори
- XPath селектори
- Методи пошуку елементів

### Lesson 3: Взаємодія з елементами
- Клік по елементам
- Введення тексту
- Вибір з dropdown меню

### Lesson 4: Синхронізація та очікування
- Waiters (очікувачі)
- Timeout налаштування
- Очікування елементів

### Lesson 5: Роботи з фреймами та вікнами
- Робота з iframe
- Нові вікна та вкладки
- Контекст браузера

### Lesson 6: Знімки та скріншоти
- Скріншоти сторінок
- Скріншоти елементів
- Запис відео

### Lesson 7: API запити та Network
- Перехоплення запитів
- Mock відповідей
- Робота з API

### Lesson 8: Page Object Model
- Структура POM
- Організація коду
- Best practices

## 🚀 Як почати

1. Почніть з `lesson-1`
2. Прочитайте README в папці уроку
3. Вивчіть файли в `examples/`
4. Виконайте вправи в `exercises/`
5. Відповідайте на питання в `QUESTIONS.md`
