    ```python

    ```

11. **Чому `enumerate()` краще за лічильник?**
    ```python
    # Варіант А
    i = 0
    for item in items:
        print(i, item)
        i += 1

    # Варіант Б
    for i, item in enumerate(items):
        print(i, item)
    ```
