# Block 8: Python Practice and Automation Preparation

Фінальний блок з'єднує все у практичні навички автоматизатора: логування, структура проєкту, CLI-скрипти, обробка логів і звітів, helper-скрипти та вступ до API-автоматизації. Це місток від «знаю Python» до «пишу тестову автоматизацію».

## 🚀 Як почати

1. Почніть з `lesson-57-logging`
2. Прочитайте README в папці уроку
3. Вивчіть файли в `examples/`
4. Виконайте вправи в `exercises/`
5. Відповідайте на питання в `QUESTIONS.md`
6. Запустіть тести: `pytest exercises/test_exercises.py -v`
