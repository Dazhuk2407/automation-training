# Вправи — Lesson 18: Run by Marker

У цій папці знаходяться практичні вправи до Lesson 18.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `marker_selection.py` — готова функція `select_by_marker` (не редагуйте)
- `exercise_1_select.py` — вправа 1: відбір за одиночним маркером
- `exercise_2_expressions.py` — вправа 2: логічні вирази and / or / not
- `exercise_3_fix_selection.py` — вправа 3: знайди і виправ неправильне очікування
- `test_exercises.py` — автоматична перевірка

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. У вправах 1–2 замініть `pass` на правильний `assert`
3. Запустіть свій файл: `pytest exercise_1_select.py -v`
4. У вправі 3 знайдіть падаючий тест і виправте очікуваний результат
5. Коли все зелене — запустіть перевірку: `pytest test_exercises.py -v`
