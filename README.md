# Python Automation Training

Курс по вивченню автоматизації тестування на Python. Включає вивчення Python, Pytest, Playwright та Git.

## Структура курсу

### 1. **Python Basics** - Основи Python
Базові концепції мови Python: змінні, типи даних, функції, ООП

### 2. **Pytest** - Фреймворк для тестування
Написання тестів, фікстури, параметризація, плагіни

### 3. **Playwright** - Автоматизація браузера
Роботи з вебдрайверами, взаємодія з елементами, синхронізація

### 4. **Git** - Контроль версій
Основи Git, гілки, комміти, pull requests

## Як користуватися цим курсом

1. Перейдіть в папку з потрібною темою
2. Прочитайте README з описом теми
3. Вивчіть приклади в папці `examples/`
4. Виконайте завдання в папці `exercises/`
5. Перевірте свої рішення за допомогою тестів

## Вимоги

- Python 3.8+
- pip (менеджер пакетів Python)
- Git

## Встановлення

```bash
git clone https://github.com/your-username/automation-training.git
cd automation-training
pip install -r requirements.txt
```
