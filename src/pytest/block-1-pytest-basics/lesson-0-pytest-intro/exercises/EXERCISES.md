## 🏋️ Вправа 1: Тестування парних/непарних чисел (EASY)

**Файл:** `exercise_1_even_odd.py`

Дано дві готові функції: `is_even(n)` та `is_odd(n)`.

**Завдання:** Напишіть тести, що перевіряють їхню роботу.

| Функція | Вхід | Очікуваний результат |
|---------|------|----------------------|
| `is_even(2)` | 2 | `True` |
| `is_even(3)` | 3 | `False` |
| `is_even(0)` | 0 | `True` |
| `is_odd(7)` | 7 | `True` |
| `is_odd(4)` | 4 | `False` |

## 🏋️ Вправа 2: Тестування рядкових функцій (EASY)

**Файл:** `exercise_2_string_utils.py`

Дано дві готові функції: `reverse_string(s)` та `is_palindrome(s)`.

**Завдання:** Напишіть тести.

| Функція | Вхід | Очікуваний результат |
|---------|------|----------------------|
| `reverse_string("hello")` | "hello" | "olleh" |
| `reverse_string("")` | "" | "" |
| `is_palindrome("racecar")` | "racecar" | `True` |
| `is_palindrome("hello")` | "hello" | `False` |
| `is_palindrome("Madam")` | "Madam" | `True` |

## 🏋️ Вправа 3: Тестування калькулятора з винятками (MEDIUM)

**Файл:** `exercise_3_calculator.py`

Дано функції: `add(a, b)`, `subtract(a, b)`, `divide(a, b)`.

**Завдання:** Напишіть тести, включаючи перевірку винятків.

| Функція | Вхід | Очікуваний результат |
|---------|------|----------------------|
| `add(2, 3)` | 2, 3 | 5 |
| `add(-1, 1)` | -1, 1 | 0 |
| `subtract(10, 3)` | 10, 3 | 7 |
| `divide(10, 2)` | 10, 2 | 5.0 |
| `divide(10, 0)` | 10, 0 | `ValueError` |

Для тесту на виняток використайте `pytest.raises(ValueError)`.
