# Block 1: Python Basics

Основи мови Python для розуміння фундаментальних концепцій, необхідних для тестування.

## 📚 Уроки (Week 1–2)

### Lesson 1: Install Python and prepare your working environment
📁 Папка: `lesson-1-install-python`
- Install Python та перевірка версії
- Підготовка робочого середовища

### Lesson 2: Install and set up an IDE (PyCharm or VS Code)
📁 Папка: `lesson-2-setup-ide`
- Встановлення IDE
- Налаштування інтерпретатора

### Lesson 3: Running Python code from terminal and IDE
📁 Папка: `lesson-3-running-code`
- Запуск з терміналу
- Запуск з IDE

### Lesson 4: Create and use a virtual environment (venv)
📁 Папка: `lesson-4-virtual-environment`
- Створення та активація venv
- Деактивація

### Lesson 5: Install packages with pip
📁 Папка: `lesson-5-pip-packages`
- Встановлення пакетів
- Оновлення pip

### Lesson 6: Working with requirements.txt (install, freeze, update)
📁 Папка: `lesson-6-requirements`
- pip freeze
- pip install -r
- Оновлення файлу

### Lesson 7: Basic Python syntax
📁 Папка: `lesson-7-basic-syntax`
- Структура файлу, коментарі, змінні
- Оператори та типові помилки

### Lesson 8: PEP 8 and Code Formatting
📁 Папка: `lesson-8-pep8-style`
- Правила PEP 8 (відступи, назвування, пробіли)
- Інструменти: black, flake8, pylint

### Lesson 9: Basic debugging in IDE
📁 Папка: `lesson-9-debugging`
- Breakpoints, step execution
- Variable inspection, call stack

### Lesson 10: Variables, basic data types, and type conversion
📁 Папка: `lesson-10-data-types`
- string, integer, float, boolean, NoneType
- type conversion, ValueError handling

### Lesson 11: Built-in functions
📁 Папка: `lesson-11-builtin-functions`
- print, input, len, range, type, isinstance
- sum, min, max, abs, round, sorted, enumerate

### Lesson 12: Understanding how Python typing works
📁 Папка: `lesson-12-python-typing`
- Динамічна типізація
- Type hints: List, Dict, Optional, Union

## 🚀 Як почати

1. Почніть з `lesson-1-install-python`
2. Прочитайте README в папці уроку
3. Вивчіть файли в `examples/`
4. Виконайте вправи в `exercises/`
5. Відповідайте на питання в `QUESTIONS.md`
6. Запустіть тести: `pytest exercises/`
