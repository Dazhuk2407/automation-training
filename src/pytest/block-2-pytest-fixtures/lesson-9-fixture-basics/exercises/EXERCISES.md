## 🏋️ Вправа 1: Оголосіть фікстуру (EASY)

**Файл:** `exercise_1_define_fixture.py`

Спочатку допишіть **три фікстури** (замініть `pass` на `return`), потім використайте їх у тестах.

| Фікстура | Що повертає |
|----------|-------------|
| `sample_number` | число `42` |
| `sample_list` | список `[10, 20, 30]` |
| `sample_user` | dict `{"name": "Bob", "age": 30}` |

| Тест | Що перевірити |
|------|--------------|
| `test_number_value` | `sample_number == 42` |
| `test_list_sum` | сума `sample_list` дорівнює `60` |
| `test_list_length` | довжина `sample_list` дорівнює `3` |
| `test_user_name` | ім'я користувача — `"Bob"` |
| `test_user_age` | вік користувача — `30` |

## 🏋️ Вправа 2: Використайте готові фікстури (EASY)

**Файл:** `exercise_2_use_fixture.py`

Фікстури `config` та `order` вже написані — **не змінюйте їх**. Додайте ім'я фікстури у параметри тесту (де його ще немає) і напишіть `assert`.

| Тест | Фікстура | Що перевірити |
|------|----------|--------------|
| `test_base_url` | `config` | `base_url` починається з `"https://"` |
| `test_timeout` | `config` (додати параметр!) | `timeout == 30` |
| `test_retries` | `config` (додати параметр!) | `retries == 3` |
| `test_order_item_count` | `order` | у замовленні 3 позиції |
| `test_order_total` | `order` | `total == 25.50` |

> Пам'ятайте: фікстуру **не викликають** дужками. Параметр уже містить значення.

## 🏋️ Вправа 3: Виправте падаючий тест (MEDIUM)

**Файл:** `exercise_3_fix_fixture.py`

Фікстура `account` написана правильно. Один тест навмисно падає.

**Завдання:**
1. Запустіть файл — один тест падає
2. Прочитайте вивід pytest: яке значення насправді у фікстурі?
3. Заповніть блок `# ВІДПОВІДЬ` у файлі
4. Виправте `assert` так, щоб тест проходив

| Тест | Стан |
|------|------|
| `test_account_owner` | працює |
| `test_account_balance` | ❌ падає — виправте очікуване значення |
| `test_account_currency` | працює |

- [ ] Усі три фікстури у вправі 1 повертають правильні значення
