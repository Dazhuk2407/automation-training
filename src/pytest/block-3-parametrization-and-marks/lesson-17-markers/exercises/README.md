# Вправи — Lesson 17: Markers

У цій папці знаходяться практичні вправи до Lesson 17.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `conftest.py` — реєструє власні маркери (`api`, `ui`, `critical`) для вправ
- `exercise_1_apply_markers.py` — вправа 1: готові маркери (smoke, regression, slow)
- `exercise_2_custom.py` — вправа 2: власні маркери + кілька маркерів на тесті
- `exercise_3_fix_marker.py` — вправа 3: знайти й виправити падаючий тест
- `test_exercises.py` — автоматична перевірка

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. У вправах 1–2 замініть `pass` на правильний `assert`
3. У вправі 3 знайдіть падаючий тест і виправте логіку
4. Запустіть свій файл: `pytest exercise_1_apply_markers.py -v`
5. Коли все зелене — запустіть перевірку: `pytest test_exercises.py -v`

> Власні маркери вже зареєстровані у `conftest.py`, тому файли збираються
> навіть під `--strict-markers`. Свої маркери придумувати не треба.
