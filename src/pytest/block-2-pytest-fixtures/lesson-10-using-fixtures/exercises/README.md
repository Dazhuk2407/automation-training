# Вправи — Lesson 10: Using Fixtures

У цій папці знаходяться практичні вправи до Lesson 10.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `exercise_1_pass_fixture.py` — вправа 1: передати фікстуру як параметр
- `exercise_2_multiple.py` — вправа 2: кілька фікстур в одному тесті
- `exercise_3_fix_usage.py` — вправа 3: виправити падаючий тест
- `test_exercises.py` — автоматична перевірка

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. Замініть `pass` на правильний `assert` (вправи 1–2)
3. Виправте падаючий тест у вправі 3 і заповніть блок `# ВІДПОВІДЬ:`
4. Запустіть свій файл: `pytest exercise_1_pass_fixture.py -v`
5. Коли все зелене — запустіть перевірку: `pytest test_exercises.py -v`
