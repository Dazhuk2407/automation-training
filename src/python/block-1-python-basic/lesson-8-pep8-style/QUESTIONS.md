# Питання для самоперевірки - Lesson 8: PEP 8 and Code Formatting

## 🎯 Теоретичні питання - PEP 8

### 1. Основи PEP 8

**Q1:** Що таке PEP 8?  
**A:** Офіційний посібник зі стилю коду для Python

**Q2:** Скільки пробілів для відступів?  
**A:** 4 пробіли (не Tab!)

**Q3:** Максимальна довжина рядка?  
**A:** 79 символів (PEP 8), або 88 символів при використанні Black

### 2. Назвування

**Q4:** Функції та змінні?  
**A:** `snake_case`

**Q5:** Класи?  
**A:** `PascalCase`

**Q6:** Константи?  
**A:** `UPPER_SNAKE_CASE`

### 3. Пробіли

**Q7:** Пробіли навколо операторів?  
**A:** Так: `x = y + 1`

**Q8:** Після коми?  
**A:** Один пробіл: `func(a, b, c)`

### 4. Структура

**Q9:** Порожні рядки між функціями?  
**A:** 2 рядки

**Q10:** Між методами класу?  
**A:** 1 рядок

**Q11:** Порядок імпортів?  
**A:** stdlib → 3rd party → local

## 🛠️ Інструменти

**Q12:** Що робить black?  
**A:** Автоматично форматує код

**Q13:** Команда black?  
**A:** `black myfile.py`

**Q14:** Що робить flake8?  
**A:** flake8 — перевіряє стиль коду та типові помилки (лінтер)

**Q15:** Різниця flake8 vs pylint?  
**A:** flake8 — перевіряє стиль та базові помилки,  
pylint — виконує глибокий статичний аналіз коду і виставляє рейтинг

## 🐛 Помилки

**Q16:** Помилка в `x=1+2`?  
**A:** Без пробілів. Правильно: `x = 1 + 2`

**Q17:** Помилка в `def MyFunction():`?  
**A:** PascalCase. Правильно: `def my_function():`

**Q18:** Помилка в `class user_profile:`?  
**A:** Класи повинні використовувати PascalCase.  
Правильно: `class UserProfile:`
