# Вправи — Lesson 2: Структура pytest проєкту

У цій папці знаходяться практичні вправи до Lesson 2.

## Файли

- `EXERCISES.md` — опис усіх завдань
- `test_exercises.py` — автоматична перевірка вашої структури

## Як працювати

1. Прочитайте завдання в `EXERCISES.md`
2. Створіть структуру проєкту в окремій папці `my_project/`
3. Запустіть перевірку:
   ```bash
   pytest test_exercises.py -v
   ```

## Важливо

- Створюйте структуру в папці `my_project/` всередині `exercises/`
- Не пропускайте `__init__.py` — без нього тести не пройдуть
